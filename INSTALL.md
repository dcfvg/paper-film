# 📱 Install Paper Film

Paper Film is a Progressive Web App. Install it for the best experience!

## 🖥️ Desktop

### Chrome / Edge / Brave
1. Click the **⊕ Install** button in the address bar
2. Or look for the install prompt at the bottom of the page
3. Click **Install**

### Safari (macOS)
1. Go to **File → Add to Dock**

## 📱 Mobile

### iPhone / iPad
1. Tap the **Share** button (□↑)
2. Scroll down to **"Add to Home Screen"**
3. Tap **Add**

### Android
1. Tap the **⋮** menu
2. Tap **"Install app"** or **"Add to Home screen"**
3. Tap **Install**

## ✨ Benefits

- 🔌 Works offline
- 🚀 Faster loading
- 🔄 Auto-updates
- 📱 Native app feel
- 💾 Settings saved locally

---

**Note:** Internet required for initial install only. Everything works offline after that!
